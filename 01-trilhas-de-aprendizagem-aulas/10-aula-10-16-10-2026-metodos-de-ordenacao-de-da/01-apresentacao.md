# Apresentação

Tipo: Página

Os **métodos de ordenação** (ou de classificação) de dados colocam uma lista de elementos em ordem, normalmente crescente ou decrescente, ou alfabética. Para ordenar os dados, esses métodos realizam uma série de operações de comparação e, se necessário, de troca. A ordenação é realizada a partir de um valor escolhido como chave de ordenação, o qual é considerado em cada elemento da lista para fins de ordenação.
