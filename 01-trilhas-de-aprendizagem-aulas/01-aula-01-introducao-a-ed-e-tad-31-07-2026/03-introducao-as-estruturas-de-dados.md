# Introdução às Estruturas de Dados

Tipo: Página

**Introdução:**

  * O que são Estruturas de Dados;
  * Estruturas de Dados e estruturas de representação: o que as linguagens de programação oferecem para implementar estruturas de dados;
  * As estruturas de dados são organizações de **memória principal;**
  * Diferença entre estruturas de dados (listas, pilhas, filas, deques, árvores, etc) e estruturas de implementação (structs, arrays, listas encadeadas - no caso da linguagem C)

**TAD: Tipos Abstratos de Dados**

  * Importância de definir um problema através de seus dados e operações para identificar estruturas de implementação mais adequadas: **o entendimento das operações permite fazer uma escolha mais adequada para a representação dos dados** ;
  * Exemplo de um banco simples, com contas, clientes e movimentações, para identificação de dados + operações
